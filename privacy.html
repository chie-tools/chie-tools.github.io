プライバシーポリシー / Privacy Policy

最終更新日：2026年10月11日

取得する情報

channel-stats は、運営者本人が許可した Google アカウントについて、YouTube Analytics・YouTube Data・Google スプレッドシート・Google ドキュメント・Google ドライブの API を通じて、運営者自身のチャンネルの統計情報と、運営者自身のファイルだけを読み書きします。

利用目的

取得した情報は、運営者が自分のチャンネルの運営状況を記録・分析するためだけに使います。

第三者への提供

取得した情報を第三者に提供・販売・公開することはありません。広告や追跡の目的では使いません。

保存と削除

許可の情報は運営者のパソコン内にだけ保存します。Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。

Google API Services User Data Policy

channel-stats's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only by the owner, is not shared with third parties, and is not used for advertising.
